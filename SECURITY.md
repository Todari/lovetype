# Security Policy

Security fixes are applied to the latest commit on `main`.

Please do not open a public issue for vulnerabilities, exposed credentials, or
deployment details. Use this repository's **Security → Report a vulnerability**
flow and include the affected component, reproduction steps, and impact.

LVTI calculates answers in the browser and does not require an account. Do not
submit real user data while validating a report. Production credentials and
environment files must remain outside the repository.
